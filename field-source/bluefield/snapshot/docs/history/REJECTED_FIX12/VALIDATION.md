# Kabul kapsamı

FIX12 nihai QA raporu exact source digest ve ZIP SHA ile bağlanır. Önceki 33 regresyon grubuna migration grubu eklenmiştir. Debug ve Production davranışları, negatif source/package policy, sanitizer, temiz extract/rebuild ve sentetik Golden tooling ayrı sonuçlardır.

Windows/MSVC/IOCP, gerçek provider ABI ve consumer/oyun testleri bu Linux ortamında NOT_RUN kalır. Yerel fixture hazırlanması veya sentetik PE araç PASS'i bu kanıtların yerini tutmaz. Kaynak paketi NON_RELEASE; resmi Golden kabulü ayrıca gerçek DLL hash'i ve ilgili protokol receipt'leri gerektirir.

Migration testi: config yokluğu, yeni tek root, eski data korunması, unsafe path/owner/width, symlink, resmi avatar exact bytes, custom/sidecar readonly, collision, malformed cache, fixed bounded log, Production no-disk, gerçek persistence failure ve ikinci commit rollback. Unit handler testleri event hazırlama/yazım hatalarında memory/event rollback sınar.
