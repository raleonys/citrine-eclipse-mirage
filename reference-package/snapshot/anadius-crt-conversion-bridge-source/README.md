# Wildcard dönüşümleri, heap, hata ve resolver kaynak bağlantısı

Bu modül yeni C++ kaynak bileşimidir; ek bir özgün binary fonksiyonu veya özgün sınıf ABI'si değildir. `BufferEffects`, kurtarılmış `06004c`/`06e430` tampon gövdelerine gerçek `malloc06a308`, `free0668c0`, `map_os_error05d698` ve `errno_cell05d724` kaynaklarını sağlar. `06ccc8`/`06cd58` dönüşüm bayrağı yardımcıları da gerçek kaynak gövdeleridir. Alt bellek ve Windows dönüşüm çağrıları zorunlu sağlayıcı olarak kalır.

`WildcardEffects`, önceki recalloc köprüsünü genişletir: geniş/dar dönüşüm metotları sıfır başlangıçlı yerel Buffer üzerinden gerçek tampon kaynağına gider. Veri adresi, sahiplik ve durum arama çekirdeğine birlikte aktarılır. Fill başarısızlığı yeni tamponu sahipli bırakabilir; arama çekirdeği uygun normal akışta onu serbest bırakır. Köprü destructor ile özgün kodda bulunmayan bir cleanup eklemez. `file_api_ansi_066c1c`, aynı runtime state üzerinde gerçek procedure0 resolver'ını, tek module16/kernel32 adayını ve gerçek fallback1 gövdesini kullanır. Tercih edilen özgün adresler çağrı hedefi yapılmaz.

Yerel `build.ps1` ve ortak `../source-workspace/build.ps1` ile **7.440 kontrol geçti**. Tam argv mode2→wildcard→search→buffer→API-policy→heap/error bağlantısı, hem yerinde hem taşınan recalloc ve ortak heap üzerinde onexit senaryoları sınandı. UTF8/ANSI/OEM seçimi, `0x100` tam BOOL, resolver cache/missing-export fallback, query/fill/malloc hataları, başarısız geniş pattern dönüşümünden literal fallback ve geçici sahiplik temizliği kontrol edilir. Aynı errno/DOS hata alanları hem fallback globalde hem canlı PTD `+0x20/+0x24` baytlarında doğrulanır. Yeniden kullanılan Buffer kapasitesi ve NULL kaynağıyla free akışı ayrıca sınanır.

Alt dönüşüm sağlayıcısı yalnız sınırları denetlenen **ASCII fixture** verisini işler; Unicode dönüşümün Windows ile eşdeğerliği test edilmiş sayılmaz. Find/locale, Heap API, modül yükleme ve function-call sağlayıcıları sentetiktir. Kendi test programı dışında hedef, özgün/yeniden derlenen DLL veya oyun çalıştırılmaz. Memory/heap/API alanı aynı canlı depolara ait olmalı; borrowed state ve sağlayıcılar adapter kullanımından uzun yaşamalıdır. Final argv için canlı pointer/char dizilerini test sağlayıcısı oluşturur. Native concurrency, locale kurucusu, gerçek Windows sağlayıcıları, SEH/unwind ve tam DLL eşdeğerliği açık kalır.

İki tampon gövdesinin kanıtları `../anadius-crt-conversion-source/evidence.json`, üç API/BOOL helper kanıtı `../anadius-crt-conversion-api-source/evidence.json` içindedir. Karşılıklı kaynak incelemeleri bu iki komşu modülde; yerel test `validation.json`, son ortak test `common-validation.json` ve `../source-workspace/build-record.json` içindedir. Eski recalloc/wildcard bağımsız testleri önceki sağlayıcılarıyla tarihsel olarak korunur; yeni bileşim onların taklit conversion metodunu kullanmaz.

Sonraki SDK aşamasında `../anadius-crt-find-bridge-source`, GetModuleFileNameW ve find SDK girişlerini gerçek argv/path/conversion/heap/error kaynaklarıyla bağladı;8.664 ortak kontrol geçti. Tipli canlı scratch/find kayıtları ve varsayılan gerçek import bağları bulunur. Testte dört Windows girişi sentetik WINAPI fixture; gerçek dosya araması/modül yolu API veya hedef DLL çalıştırılmaz. Bu klasörün bağımsız test arayüzleri/kayıtları korunur; native Unicode/locale/concurrency ve tam DLL/SEH eşdeğerliği tamamlanmadı.
