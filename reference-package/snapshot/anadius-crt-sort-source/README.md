# CRT sıralama çekirdeği

`sort.cpp`, `anadius64.dll` içindeki `0x1800768f0` gövdesinin normal akışını bağımsız C++20 olarak yeniden kurar. Bu bir `std::sort` sarmalayıcısı veya hazır başarılı dönüş değildir. Gerçek gövde, sekiz ve daha az elemanda en büyük elemanı sona taşıyan sıralamayı; büyük aralıklarda üç adaylı pivot seçimini, çift yönlü bölümlemeyi, eşit eleman taramasını ve iki adet 62 girişli bekleyen aralık dizisini içerir.

`Effects` bütün adresleri `uint64_t` kimlikleri olarak taşır. Bayt okuma/yazma, karşılaştırma çağrısı, `0x18005d724` errno hücresi ve `0x18005c954` geçersiz parametre işlemi zorunludur. Yerel işaretçi dönüşümü veya hedef kod çağrısı yoktur. Hücre yazımı mevcut `crt_errors_recovered::Cell32` aracılığıyla yapılır; yanlış hizalı PTD verisi için sahte `int&` oluşturulmaz.

Geçersiz koşul `(base == 0 && count != 0) || width == 0 || comparator == 0` olduğunda önce errno `22` olur, sonra geçersiz parametre işlemi çağrılır. İşlem geri dönerse fonksiyon da döner. Geçerli `count < 2` çağrısı belleğe veya errno'ya dokunmaz. Ghidra'nın `__doserrno` etiketi assembly'deki `0x18005d724` çağrısıyla düzeltilmiştir.

Bayt takasında sağ bayt okunur, sol bayt okunur, sola sağ değer yazılır, sağa sol değer yazılır. Aynı adres takası atlanır. Sağlayıcı bir yazmada hata verirse ek geri alma veya SEH temizliği üretilmez. Adres karşılaştırmaları unsigned, `0x180076c58..c60` aralık uzunluğu seçimi signed `CMP/JL` olarak modellenmiştir. Orijinalde bulunmayan 62 giriş taşma koruması yalnızca desteklenmeyen girdide C++ bellek bozulmasını önler.

`compare_slot_addresses_06e41c`, Ghidra'nın tanımlı fonksiyon listesi dışında kalan 18 baytlık karşılaştırıcının ayrı, sınırlı çevrimdışı byte kanıtından yeniden yazımıdır. `RCX` ve `RDX` adreslerinin kendisini unsigned karşılaştırır; slot içindeki işaretçiyi veya metni okumaz. Bu karşılaştırıcıyla genel sıralama gövdesi gerçek karşılaştırma çağrılarını yapar, ancak zaten artan slot adresleri nedeniyle hiçbir bayt takası gerekmez. Bu sonuç joker eşleşmelerinin alfabetik sıralandığı anlamına gelmez.

`build.ps1` mevcut yerel LLVM/MinGW derleyicisiyle üretim nesnesini ve bağımsız sentetik testi oluşturur. 4.831.748 kontrol; 2–8 elemanın bütün permütasyonlarını, 9–160 elemanın farklı kayıt boylarında ters/sıralı/eşit/rastgele girdilerini, dokuz eleman için tam 23 karşılaştırma çağrısını, 512 elemana kadar adres karşılaştırıcısının yazma yapmadığını, unsigned uç adresleri, errno sırasını ve kısmi yazma hatasını kapsar. Bütün erişimler sınırlı fixture belleğindedir.
