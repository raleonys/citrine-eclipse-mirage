# SDK dosya arama ve modül yolunu argv kaynaklarına bağlama

Bu modül yeni kaynak bileşimidir; özgün bir sınıf veya ek bir binary fonksiyonu değildir. `WildcardEffects`, önceki conversion/recalloc köprüsünü genişletir ve üç dosya arama metodunu gerçek `crt_find_native::Session` gövdesine bağlar. Session tipli `WIN32_FIND_DATAW` kayıtlarını yaşatır, FindFirstFileExW/FindNextFileW/FindClose SDK çağrılarını sağlar. Varsayılan API tablosu gerçek import'lara bağlıdır; bu aşamadaki test tablosu üç WINAPI fixture kullanır. Gerçek dosya araması yapılmaz.

`PathEffects`, mevcut dönüşüm/heap/error kaynaklarına delegasyon yapar; codepage seçimini gerçek `select_code_page_region` üzerinden aynı locale/PTD alanına bağlar. `Policy`, argv'nin module-filename metodunu gerçek `module_filename_06ecdc` → `fixed_to_narrow_0601c8` kaynaklarına bağlar. `SdkPathProvider` tipli GetModuleFileNameW girişini ve caller'a ait canlı 264 WCHAR scratch'i kullanır. Özgün gövde geniş API'ye **261** kapasite, argv'nin dar tamponuna **260** kapasite verir. Kapasite hatası34 korunur; module-filename durum kodunu göz ardı edip uzunluğu döndürür. Kaynak cookie/SEH veya özgün stack ABI'si olarak sunulmaz.

`SdkPathProvider` varsayılan gerçek SDK girişini alır; testte tipli `fixture_module` enjekte edilir. Scratch ve hedef tampon, sağlayıcıların aynı canlı bellek alanında olmalıdır. Her modül-yolu çağrısı bitene kadar kendi scratch'i korunmalı; örtüşen çağrılar ayrı scratch/provider kullanmalı veya dışarıda seri çalıştırılmalıdır. NUL'suz/truncated geniş API çıkışının özgün olası sınır dışı okuması yeniden üretilmez; başarılı sağlayıcı yolu NUL ile bitmelidir. NULL getter ve kapasitenin 264'ü aşması yeni kaynak destek sınırlarıdır, özgün hata davranışı değildir.

**8.664 ortak kontrol geçti**. Tam argv mode1/mode2, joker search/append/qsort, dönüşüm/API/heap/error/resolver ve önceki onexit kaynakları birlikte çalışır. SDK fixture'ları aynı canlı find kaydını doldurur; filename okumaları yalnız Session'ın canlı 520 baytlık alanı içinde yapılır. FindNextFileW için `0x100` tam BOOL, directory attribute'larının filtrelenmemesi, OOM'da arama/depoya ait temizleme, NULL pattern dönüşümünden literal fallback ve explicit close doğrulanır. Modül yolu için komut satırı yokken fallback.exe, GetModule hatasında eski dar hedefin korunması, 260 karakterlik geniş yolun dar hedefte34 vermesi ve locale bayrağı temizliği sınanır. GetModule/Find gerçek API'leri veya hedef DLL çalıştırılmaz.

Alt karakter dönüşümü ASCII fixture; locale, Heap API, module resolver ve diğer uygulama sağlayıcıları sentetiktir. Native Unicode/concurrency/loader/global yaşam süresi, SEH/unwind ve tam DLL eşdeğerliği açık kalır. SDK Session destructor'u FindClose çağırmaz; özgün normal akışın explicit close sırası korunur, fault durumuna yeni cleanup eklenmez. Standalone test/validation ve son ortak build kayıtları ayrı tutulur.

Adres/Evidence için `../anadius-crt-module-path-source/evidence.json`, `../anadius-crt-find-native-source/evidence.json`; karşılıklı inceleme için bu klasörlerin `review-find.json` ve `review-path-bridge.json` dosyalarına bakılabilir. Köprü ve SDK girişleri yeni C++ kodudur, özgün fonksiyon envanterini artırmaz.
