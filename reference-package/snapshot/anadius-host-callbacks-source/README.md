# CreateProcess / SHGetFolderPath callback kaynakları

Bu C++20 modülü `anadius64.dll` SHA-256 `9e420c3aae5ea26410f0bf578f86c47e51e36ff770b9e2a28b5eaee46aed786c` içindeki dört callback ve iki klasör yardımcısının uygulama mantığını yeniden kurar. Bağımsız DLL veya özgün C++ kaynak değildir. Paylaşılan map çözümleme ve CRT karşılaştırmaları `anadius-registry-source` içindedir.

`create_process_a_00f3f0` / `create_process_w_00f4d0` yalnızca `lpApplicationName` ile `Values["ClientPath"]` değerini karşılaştırır. Command line taranmaz; eksik application pointer'ı orijinal işleme geçer. Eşitlikte gerçek process çağrısı yapılmaz ve sıfır döner. Decompiler'ın `void` prototipi yanıltıcıdır: assembly'deki `TEST EAX,EAX; JZ` sonrasında epilog EAX'i değiştirmez. Diğer dal, bütün on parametreyi ve orijinal BOOL sonucunu korur. Callback ayrıca LastError veya process-information alanlarını yazmaz; zorunlu karşılaştırma/CRT backend'inin yan etkileri bu modülde taklit edilmez.

`folder_value_a_008db0` / `folder_value_w_008fa0` tam CSIDL değerinin `5` olmasını ister. Örneğin `0x8005` eşleşmez. `Documents` map anahtarı büyük/küçük harfe duyarlıdır. Çözümlenen uzunluk sıfırsa callback orijinal SHGetFolderPath'e geçer; aksi halde `strcpy_s` / `wcscpy_s` 260 karakter kapasitesiyle çağrılır. Kopya başarılıysa sonuç `0`, herhangi bir CRT hata kodunda `1` olur. Bu, HRESULT hata eşlemesi yapmaz ve kopya hatasında orijinal API'ye dönmez. Uzunluk dolu olup ilk karakter NUL ise override dalı seçilir ve C-string olarak boş metin kopyalanır. Wide kapasite de 260 UTF-16 birimidir.

`Effects` zorunlu orijinal API çağrıları, filesystem kod sayfası dönüşümü, gerçek locale/CRT karşılaştırması ve secure-copy politikası ister. Bunlara başarı döndüren varsayılan implementasyon eklenmemiştir. Secure CRT invalid-parameter handler, null/yanlış boyutlu hedef bellek, exception/EH ve gerçek hook/Win32 ABI bağlantıları açık kalır. Synthetic test kopya politikası, özgün CRT'nin tüm yan etkilerine eşitlik iddiası değildir. Native process/folder/registry çağrısı çalıştırılmaz.

`build.ps1` güvenilir mevcut LLVM MinGW derleyicisiyle kendi test EXE'mizi derleyip çalıştırır. Testler sentetik map/string/buffer ve zorunlu API mock'ları kullanır; kullanıcı profili veya yapılandırması okunmaz. Ek entegrasyon senaryosu gerçek `initialize_host_00e310`, Windows lexical-path modülü, paylaşılan registry map yardımcıları ve bu callback'leri birlikte kullanır: doldurulan `ClientPath` process engellemesine, `Documents` klasör kopyasına ulaşır; yeniden başlangıç ve hook motoru hatası eski override'ları korumaz. Bunun için standalone test registry.cpp, host_init.cpp ve paths.cpp ile bağlanır. Bir üretim source nesnesi ve bir test grubu ekler. `validation.json` son çalıştırmayı ve kaynak hashlerini, `evidence.json` adres ve kanıtları içerir.
