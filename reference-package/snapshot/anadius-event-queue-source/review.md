# Event queue: bağımsız üretim kaynağı incelemesi

Sonuç: **PASS; belirtilen normal akış ve sağlayıcı alanında maddi bulgu yok.** İnceleyen `event_queue_audit`. İncelenen dört üretim dosyası `outputs/anadius-event-queue-source/queue.hpp`, `queue.cpp`, `adapters.hpp`, `adapters.cpp`; dondurulan hash'ler JSON kaydındadır. Bu inceleme test yürütme veya özgün binary differential doğrulaması değildir.

Dayanak `event-queue-flow-audit.md/json` içinde adres ve Evidence kimlikleriyle çıkarılmış native getter/üretici/tüketici akışıdır. Önceki CRT veya diğer üretim kaynakları bu inceleme tarafından değiştirilmedi; özgün DLL/oyun çalıştırılmadı, gerçek kullanıcı dosyaları okunmadı.

- `mutex_02c620` ve `queue_02c400`, signed32 `thread_epoch < guard`, header sonrası guard'ın yeniden -1 denetimi, constructor/seed işlemi, atexit kayıt çağrısı ve footer sırasını korur. Header bekledikten sonra başka guard değeri bırakırsa constructor/register/footer atlanır. Getter her yolda aynı caller-owned global nesne referansını döndürür. Guard/TLS başlangıçları tahmin edilmez; Context tarafından verilir.
- Mutex constructor flags değeri 2'dir. Cleanup enum değerleri native `07e030` ve `07e000` kimliklerini temsil eder; imaj adresleri callback olarak yürütülmez. `register_atexit` dönüşü yoksayılır. Native guard/header/footer/atexit kayıt sistemi zorunlu sağlayıcıdır. Callback yürütme ve native teardown uygulanmış sayılmaz.
- Queue getter 68 bayt DOWN event'ini `construct_seed_copy` sınırına verir. Native proxy/map/block/string tahsisleri ve seed kopyası bu zorunlu sınırda tutulur. Bu sınırın provider exception'ları normal register/footer satırlarına ulaşmaz; genel native EH/abort/retry/partial-construction eşitliği iddia edilmez.
- `OwnedStorage` açık std::deque/string FIFO compatibility uygulamasıdır. Seed'in kendi kopyasını tutar; append sonrası kaynak string'i mantıksal olarak boşaltır, CStr kesmesi yapmadan embedded NUL baytlarını korur; front kopyası ve pop sırası normal FIFO davranışını sağlar. Native map/growth034660/allocator/SSO/capacity veya failure footprint'i olarak sunulmaz. Storage-not-constructed, double-construct ve empty-front/pop için yeni domain hataları açıkça seçilmiş kaynak guardlarıdır.
- OwnedStorage'ın atomik `published_size_` alanı yalnız relaxed nonempty sorgusu içindir; deque içeriğine diğer erişimler caller tarafından seri hale getirilmelidir. Relaxed atomic yayın tercihinin veya host mutex sağlayıcısının native concurrency/memory-model eşitliği olduğu sonucu çıkarılamaz. Context/guard/runtime/storage/mutex ömürleri ve yayını caller yükümlülüğüdür.
- Üç adapter aynı Context ve dolayısıyla aynı storage/mutex/guard kimliğini paylaşır. Adapter'lar ekstra kilit eklemez; mevcut recovered caller'lar sıralamayı belirler. IGO lock getter ile native mutex'e gider, acquire ile queue getter'ı çalıştırır, sonra aynı storage'a event taşır. Content predicate, native grant'in queue-getter çağrısını mevcut event lock altında yapar ve başarıda true dönerek ikinci seed girişimini önler. Doğrudan initialize metoduna farklı seed verilmesi yeni açık domain hatasıdır.
- Message adapter'ın `nonempty_relaxed()` metodu queue getter'ı çalıştırır; bu, native `0342f4` getter'ın mutex `034307`'den önce olmasını korur. Sonraki locked recheck/front/pop aynı storage üzerinde kalır, getter tekrar çağrılmaz. Böylece cold consumer seed oluşturabilir; cold IGO iki DOWN, cold completion grant seed+achievement event sırasını koruyabilir. Bu caller sonuçları ayrıca entegrasyon testleriyle doğrulanmalıdır.
- İlk erişim yolu iki bağımsız lazy global'in kayıt sırasını değiştirir: cold consumer queue cleanup'ını mutex'ten önce, cold producer mutex cleanup'ını queue'dan önce kaydeder. Kaynak bu sırayı zorlamaz; tek sabit cleanup sırası veya tam native lifecycle kanıtı ileri sürülmemelidir.

Sınırlamalar: İki normal getter gövdesi, abstract native initialization/storage sınırları üzerinde kurtarılmıştır. Yeni adapter'lar ayrıca keşfedilmiş özgün yordam sayılmaz. Host FIFO backend'in genel allocator/SEH/ABI/native initialization ve whole-DLL eşitliği açık kalır. Bu PASS yalnız incelenen frozen üretim kaynakları ve belirtilen normal sağlayıcı sözleşmeleri içindir; daha sonraki değişiklikleri otomatik kapsamaz.
