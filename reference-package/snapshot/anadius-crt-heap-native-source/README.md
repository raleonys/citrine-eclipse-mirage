# Windows heap API bağlantısı

Bu yeni SDK katmanı `GetProcessHeap`, `HeapAlloc`, `HeapReAlloc`, `HeapFree`, `HeapSize` ve `GetLastError` için gerçek Windows importlarını sunar. DLL'den çıkarılan yeni fonksiyon gövdesi sayısı **0**. Orijinal malloc/calloc/realloc/free/heap başlatma algoritmaları önceki kaynak modüllerindedir; bu modül onların native API sınırını karşılar. Üst `Effects` bağlantısı ayrı modüldedir.

`Api` alanları SDK fonksiyonlarının `decltype` türlerini kullanır; `WINAPI` çağrı imzası korunur. `Calls` tabloyu değer olarak kopyalar ve altı girişin tamamını NULL bakımından doğrular. Tablonun nesne ömrü çağrı nesnesinden kısa olabilir; fonksiyon kodunun çağrı süresince yüklü olması gerekir. Varsayılan tablo Windows importlarını kullanır.

Adapter heap kimliğini, flag'leri, pointer'ları ve 64-bit `SIZE_T` değerlerini değiştirmeden iletir; argümanlar üzerinde normalizasyon, adres çevirme, ayırma kaydı veya gizli sahiplik işlemi yapmaz. `HeapSize` hata işareti olan tüm bitleri 1 değeri de aynen korunur. `HeapFree` sonucu üst arayüzün `bool` türüne tam SDK `BOOL != 0` karşılaştırmasıyla çevrilir. `last_error()` doğrudan ham `DWORD` değerini verir. Çağrılardan önce/sonra `LastError` sıfırlanmaz, korunmuş eski değer geri yazılmaz. Native hata ve exception davranışını değiştirmek için koruyucu blok eklenmez. API tablosu NULL ise kurucunun `invalid_argument` üretmesi yeni katmanın açık sınırıdır.

Heap ve blok ömrü çağıranın sorumluluğundadır. Üretim katmanı C++ nesne ömrü başlatmaz. Gerçek test, her başarılı alloc/realloc sonrasında non-value-init placement-new ile unsigned char dizisi ömrünü açıkça başlatır; içerik başlatılmadığı için zero-fill ve realloc prefix kontrolleri önceki native baytları okur. Özellikle process heap ödünç alınır; bu katmanda `HeapDestroy`, destructor ile otomatik free veya sahiplik devri yoktur. Gerçek native yolda tüm handle, pointer, boyut ve flag'ler Windows API'nin geçerli alanında olmalıdır. Testlerin geçersiz/opak pointer ve tam bit genişliği örnekleri yalnızca SDK imzalı sentetik fonksiyonlara gider.

`build.ps1` C++20 `-O2 -Wall -Wextra -Werror` ile bir üretim nesnesi ve statik test EXE'si oluşturur. **169 kontrol geçti:** altı NULL tablo girişinin reddi; tablonun kopyalanması; sıfır/yüksek-bit/tüm-bit boyut ve handle aktarımı; tam BOOL sonuçlarının normalizasyonu; hata sentinel'i; ham error aktarımı. Gerçek Windows testleri yalnızca `GetProcessHeap` ve kendilerine ait 32→96→16 bayt blok üzerinde alloc/realloc/size/free, ilk zero-fill ve kopyalanan içeriğin doğrulanmasıdır. `SetLastError`, test EXE'sinde ham okuma kontrolü için kullanılır; üretim tablosunda yer almaz. Orijinal DLL, yeniden oluşturulmuş DLL veya oyun çalıştırılmaz; dosya, registry, network, hook ve thread işlemi yapılmaz.

Bu kontrol orijinal DLL ile çalışma zamanı eşdeğerliği kanıtlamaz. Global başlangıç, cookie/new-handler sahipliği, lock/FLS/PTD altyapısı, DLL ömrü ve ABI/SEH uyumu bu modülden çıkarılamaz. `evidence.json` önceki binary kanıtlarını, `provenance.json` yerel SDK ve kaynak SHA256 değerlerini, `validation.json` yürütülen kontrolün kimliğini kaydeder.
