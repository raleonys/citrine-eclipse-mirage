# Sabit dönüşüm tamponu ve modül yolu: 0601c8 / 06ecdc

`module_path.cpp`, `anadius64.dll` içindeki `0x1800601c8` sabit UTF-16→dar metin tampon yönetimini ve `0x18006ecdc` modül adı yardımcısını yeniden yazar. Kaynak, mevcut `crt_conversion_recovered::Buffer/Effects` arayüzünü kullanır. `Buffer`, özgün `+10/+18/+20/+28` alanlarının yeni kaynak temsilidir; tam nesne düzeni veya ABI değildir. Özgün kullanılmayan üçüncü dönüşüm parametresi yeni arayüzde yoktur.

`0601c8` tahsis veya free çağırmaz. NULL kaynak `data/capacity/length/owned` alanlarını sıfırlar. Boş kaynakta kapasite varsa yalnız bir sıfır baytı yazılır ve uzunluk sıfırlanır. Yetersiz kapasite errno=34 yazar, sahipliği ve kapasiteyi sıfırlar; eski veri adresi ve uzunluk korunur. Sahiplik biti set olsa bile bellek bırakılmaz. Bu fark mevcut büyüyebilen `06e430` dönüşüm gövdesinden ayrıdır.

Boş olmayan kaynakta ilk `06cd58` çağrısı `cp,0,source,-1,NULL,0,NULL,NULL` ile boyutu sorgular. Sorgu `MOVSXD` ile işaretli genişletilip kapasiteyle işaretsiz karşılaştırılır. Doldurmada kapasitenin alt DWORD'u aynı bitleri koruyan işaretli int olarak geçirilir. Sonuçların yalnız sıfır olması hata kabul edilir; negatif sorgu/doldurma sonuçlarının tuhaf sınır davranışı sentetik testlerle korunur. Başarıda uzunluk işaretli genişletilen sonuç eksi birdir. API hatası `GetLastError -> 05d698 -> 05d724 hücresini oku` sırasını izler. `05d724`, decompiler'ın `__doserrno` adının aksine errno hücresidir.

`06ecdc` önce `GetModuleFileNameW(module,scratch,261)` çağırır; dar hedefte 260 kapasite kullanılması bu 261 kod birimlik geniş scratch isteğini değiştirmez. API sonucu yalnız sıfıra karşı test edilir. Sıfırda LastError eşlenir ve sıfır döner. Diğer sonuçlarda hedef kapasitesi alt DWORD'a kırpılır, ödünç `Buffer` uzunluk=0/sahiplik=0 ile kurulur. UTF-8 veya file-API ANSI/OEM seçimi ve locale temizliği `choose_code_page` etkisine ayrılmıştır; üst bileşim mevcut `select_code_page_region` gövdesine bağlayabilir. Gerçek `0601c8` çağrısının durum kodu göz ardı edilir; uzunluğun alt DWORD'u döner. Dolayısıyla dönüşüm/kapasite hatası errno etkisini koruyarak sıfır uzunluk döndürebilir.

`WideResult`, özgün yerel stack tamponunun yeni sağlayıcı arayüzüdür. Sağlayıcı çağrı boyunca en az 261 UTF-16 kod birimlik scratch'i canlı tutmalı ve desteklenen başarı yolunda NUL ile biten veriyi döndürmelidir. Özgün yordamın NUL'suz/truncated API çıkışında olası sınır dışı okuması emüle edilmez. Bu geçerli bellek sözleşmesi statik gözlem değil, yeni kaynak sınırıdır. Özgün stack/cookie/SEH ABI yeniden kurulmadı. Gerçek Windows modül yolu, dönüşüm ve locale sağlayıcıları soyut kalır; bu modül tek başına tam DLL değildir.

`build.ps1`, mevcut LLVM-MinGW ile C++20 `-O2 -Wall -Wextra -Werror` altında bir üretim nesnesi ve sentetik test programı derler. **3.469 kontrol**; NULL/boş kaynak, kapasite sınırları, 34 hata yolu ve sahiplik zamanı, ödünç tampon, NUL/sonek korunumu, sorgu/doldurma hataları, negatif sonuçlar, DWORD kırpılması, 261/260 ayrımı, API/locale/hata sırası, yok sayılan durum ve döndürülen uzunluk sınırlarını kapsar. Orijinal DLL veya gerçek Windows modül/dönüşüm sağlayıcıları çalıştırılmaz.

`collect-evidence.ps1`, özgün DLL ve iki saklanan bütün analiz dosyasının SHA-256 değerlerini ve dört Evidence ID'nin saklanan REA kaydında tekilliğini doğrular. Yalnız bu iki fonksiyonun assembly/pseudocode metinleri çıkarılır. `evidence.json` adres ve kanıt eşlemesini; `validation.json` derleyici kimliği, üretim/test hash'lerini ve test sonucunu içerir.

Sonraki SDK aşamasında `../anadius-crt-find-bridge-source`, GetModuleFileNameW ve find SDK girişlerini gerçek argv/path/conversion/heap/error kaynaklarıyla bağladı;8.664 ortak kontrol geçti. Tipli canlı scratch/find kayıtları ve varsayılan gerçek import bağları bulunur. Testte dört Windows girişi sentetik WINAPI fixture; gerçek dosya araması/modül yolu API veya hedef DLL çalıştırılmaz. Bu klasörün bağımsız test arayüzleri/kayıtları korunur; native Unicode/locale/concurrency ve tam DLL/SEH eşdeğerliği tamamlanmadı.
