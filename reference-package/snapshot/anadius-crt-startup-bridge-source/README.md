# Ortam, SList ve cexit için dış CRT kaynak köprüsü

`startup_bridge.cpp`, önceki `LifecycleBridge` üzerinde yedi dış CRT metodunu gerçek kurtarılmış gövdelere bağlar: SList initialize/release, stdio seçenekleri, TLS slotu, narrow environment init, termination-begun getter ve `cexit`. `TerminationTablesBridge` iki terminator range seçimini gerçek `initterm_064614` kaynak yürüyüşüne bağlar. Bu yeni entegrasyondur; ek özgün fonksiyon kurtarımı sayılmaz. Modüllerin Evidence kayıtları `evidence.json` içindedir.

`StartupBridge` tüm state/provider'ları referansla ödünç alır. Entry'nin application onexit tablosu, termination state'in referans verdiği `onexit.application_0a47a8` ile aynı nesne olmalıdır. Cookie bütün encoded hücreler ve resolver state ile uyumlu olmalıdır. Termination callback hücresi cache modülünün `a4f10` hücresine referanstır; kopya tablo/callback oluşturulmaz. PTD, provider, slot ve rebuilt callback bağları tüm geç FLS/TLS callback'lerinden uzun yaşamalıdır. Dış çağrıların serialization/shutdown sorumluluğu caller'dadır.

Yedi metodun adresleri: `04c1e0`, `04c1f0`, `04c1fc`, `04c218`, `064054`, `05cdb8`, `05cd9c` (image base `0x180000000`). Ortam init dönüşü, dış CRT'de olduğu gibi yok sayılır. Getter, begun DWORD `A4F08` değerini okur; `cexit` bunu1 yaparken permanent-completed byte `A4F18` sıfır kalabilir. Sonradan ikinci DLL detach, attach sayacı sıfırsa application veya cleanup çalıştırmadan reddedilir.

`TerminationTablesBridge` 4 ve1 elemanlı canlı/mutable rebuilt-binding span'ları alır. Exact half-open metadata seçicileri `0x18007f728..0x18007f748` ve `0x18007f750..0x18007f758`'dir. Diğer seçiciler ve yanlış tablo genişlikleri açıkça unsupported input olarak reddedilir. Walker sonraki slotları ulaştığında yeniden okur. `termination-tables.json` özgün tablonun null slotlarını ve `0x180065338`, `0x180077b18`, `0x18005224c` callback VA'larını bounded, SHA kontrollü PE okumasıyla kaydeder. Bu VA'lar doğrudan çalıştırılmaz; üç callback'in gerçek alt sistem bağları henüz tamamlanmış değildir.

`./build.ps1` **1.732 ortak kontrolü** geçti. Test, gerçek kurtarılmış Entry/VCRT/ACRT/PTD/CPU/lock/environment/cexit/onexit/support kaynaklarını çalıştırır. FLS var/yok, ortam conversion hatası ve TLS validation sırasında slot değiştirme için8 kombinasyon vardır. Slot validation ve callback'in gerçekten birer kez çağrıldığı ayrıca sayılır. Gerçek onexit kaydı ve LIFO, encoded callback, sonraki terminator slotunun callback tarafından değiştirilmesi ve cleanup sonrası boşalan15 kilit/iki PTD slotu kontrol edilir.

Test fixture'ları `../anadius-vcrt-bridge-source/test_fixtures.hpp` ile ortaktır; test sayıları bağımsız davranış kapsamı paydası değildir. Sabit cookie önceden seçilidir; entropy→immutable resolver kurulumu burada tamamlanmış sayılmaz. C/C++ initializer tabloları testte boştur; terminator slotları rebuilt test callback kimlikleridir. Ortam fixture'ı yalnız programın kendi byte/pointer allocation'larını kullanır, gerçek ortamı okumaz. Ortam array'i örnek sonrasında ayrıca serbest bırakılır; bu işlem tam CRT environment shutdown bağının kurulmuş olduğu iddiası değildir.

Native OS/ASIO/provider, tam init/termination callback'leri, cookie/global başlangıç düzeni, argv, TLS image validation, SEH/unwind, loader/export ABI ve tam DLL linkleme açıktır. Özgün/yeniden derlenen DLL ve oyun çalıştırılmadı. Bağımsız `review-termination.json` kaydı ve ortak derleme sonucu ayrı korunur; test başarısı tam binary eşdeğerliği değildir.

Sonraki argv aşamasında test fixture'ları `test_fixtures.hpp` ortak başlığına taşındı; üretim startup_bridge.hpp/cpp değişmedi. Bağımsız incelemenin eski test hash'i önceki dosya düzenine aittir. Güncel ortak build, source-snapshot ve review-fixture-refactor.json yeni test/header düzenini kaydeder. Eski1.732 kontrol korunur; yeni argv entegrasyonu aynı fixture'ı kullanır.
