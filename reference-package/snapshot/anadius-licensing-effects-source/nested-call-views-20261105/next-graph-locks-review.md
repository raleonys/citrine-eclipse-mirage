11. Current global `(achievement_locked && Native-event-lock)` and `dispatch:328` any-lock prechecks must inspect the current execution's ownership, not a different actor. Preserve actual same-actor lock-order/nonrecursive constraints; don't invent a cross-session or per-session strand.
