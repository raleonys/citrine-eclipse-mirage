# Dosya durumu ve Win32 bağlantısı

`status.cpp`, `anadius64.dll` içindeki `0x18001ea20` durum dönüştürücüsünü yeniden yazar. `UsedStats`, çağrılan `0x180049104` işlevinin **flags=3, cached attributes=0xffffffff** alanını somut olarak uygular; genel işlevin bütün bayrak birleşimlerini uygulamaz. `NativeStats` bunu gerçek Win32 çağrılarına bağlar. Bu klasör tek başına DLL değildir ve MSVC `std::filesystem` nesne yerleşimini taklit etmez.

`Status` alanları özgün sonuç yapısının +0/+4/+8 alanlarına karşılık gelir. Hata 2, 3, 53 veya 123 olduğunda `kind=1`, diğer hatalarda `kind=0`, izinler `0xffff` olur. Başarıda readonly biti izinleri `0x16d`, aksi durumda `0x1ff` yapar. Dizin biti `kind=3`, normal dosya `kind=2` üretir. Geçerli reparse tag sağlandığında `0xa000000c → 4`, `0xa0000003 → 10` eşleşmeleri korunur. Bunlar özgün sayısal değerlerdir; yeni bir sınıflandırma icat edilmedi.

Kullanılan native yol `GetFileAttributesExW` ile başlar. Yalnız hata 32 sonrasında `FindFirstFileW` denenir. `FindClose` sonucu özgünde olduğu gibi denetlenmez. Reparse biti görülürse `CreateFileW` erişim `0x80`, paylaşım 7, disposition 3, flags `0x02000000` ile açılır; ardından `GetFileInformationByHandleEx(FileBasicInfo, 0x28)` çağrılır. `FILE_FLAG_OPEN_REPARSE_POINT` eklenmez. Açılmış handle kapatılamazsa özgün `abort` davranışı korunur. Üretim adapterinde sessiz başarı gövdesi bulunmaz.

Önemli kanıt sınırı: flags=3 yolu reparse tag alanı +0x14'ü **yazmaz**. Takip edilen handle'ın `FileBasicInfo` sonucu hâlâ reparse biti taşıyorsa `0x18001ea20`, özgünde başlatılmamış stack alanını okur. Kaynakta bunu sıfır kabul etmek yerine `StatsResult::reparse_tag` boş tutulur ve bu özel alan `OutOfEvidenceStatus` hatasıyla görünür kılınır. Genel `Stats` sağlayıcısı yalnız bilinen gerçek bir tag varsa bunu sunabilir. `UsedStats` desteklenmeyen bayraklarda aynı türde bir alan hatası verir; bu hata özgün ABI veya özgün Win32 hata kodu olarak sunulmaz.

`UsedStats`, durum çağıranının gerçekten kullandığı attributes alanını döndürür. Özgün istatistik yapısının timestamp/size/link-count alanları ve alternatif bayrak yolları tam bir ikili yapı olarak dışarı sunulmaz. Bilinmeyen tag, tahmini başlangıç verisi veya `std::filesystem::status` ile değiştirilmez. Path bir UTF-16 dizisidir; native C string çağrıları ilk NUL'da biter. Asıl MSVC string kapasite/SSO ayrımı C++ uyarlamasında mevcut değildir.

`build.ps1` C++20 kaynakları derler ve 9.307 denetimi çalıştırır. Sentetik syscall testleri hata/FindFirst/reparse/close/abort sırasını doğrular. Gerçek native testler yalnız test exe'sinin yanındaki üretilmiş `build/status-fixtures` dosyası ve dizinini kullanır: normal dosya, dizin, eksik dosya, readonly değişimi, `CreateFileW`/`FileBasicInfo`/`CloseHandle`, `FindFirstFileW`/`FindClose`. Readonly biti test sonunda geri alınır. Gerçek symlink veya junction oluşturulmaz; reparse ve hata yolları mock ile sınanır. Özgün DLL, oyun EXE'si veya CFG yüklenmedi, çalıştırılmadı, değiştirilmedi. Bu denetimler özgün DLL ile çalışma zamanı eşitliği kanıtı değildir.

Adresler, REA Evidence kimlikleri ve kapsam `evidence.json` içindedir. Tam assembly/pseudocode üst klasörde korunur.
