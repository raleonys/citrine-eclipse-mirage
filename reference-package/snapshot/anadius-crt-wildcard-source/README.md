# Argv joker genişletmesi ve kaynak bileşimi

`wildcard.cpp`, `anadius64.dll!0x18006e5bc` genişletme çekirdeğini, gerçek JMP thunk `0x18006ecd4`, `_mbsdec_l` `0x180077170` ve NULL-locale wrapper `0x180077168` normal akışlarını yeniden kurar. Girdi SHA-256 `9e420c3aae5ea26410f0bf578f86c47e51e36ff770b9e2a28b5eaee46aed786c`. `evidence.json` saklanan REA Evidence kimliklerini ve alt modül kanıtlarını birleştirir. Bu kaynak tam DLL veya özgün kaynak değildir.

Çekirdek her argümanda ilk `*`/`?` byte'ını arar; bulunmazsa gerçek `append_06e800`, bulunursa gerçek `search_06e984` kaynağını kullanır. Sonrasında pointer/karakter toplamını sayar, gerçek `063888` tahsis yardımcısını ister, stringleri tek output tahsisine kopyalar, output pointer'ını yayımlar ve geçici string/vektörü bırakır. Per-argüman hata sonucu low EAX olarak döner; final tahsis hatası `0xffffffff` döndürür. NULL output hücresinde errno22 ve returning invalid handler çağrılır. Kopya hatasında Watson gereklidir; kaynakta normal yola eklenmeyen cleanup çalışmaz.

`Result::pointer_slots` yalnız yeni bounds metadata'sıdır; özgün output hücresi değildir. Başarılı output allocation gerçek, canlı ve NULL ile biten `char*[]` ile ardından gelen `char[]` depolamasını taşımalıdır. `ExpansionPolicy`, bu depoyu actual `configure_0638e8` mode2 sonucuna bağlar. Aynı heap/provider bütün allocation/free işlemlerini yönetmelidir. Girdi argv/string blokları geçerli ve sabit; vector aralığı geçerli, hizalı ve sonlu olmalıdır. Pointerlar özgün image fonksiyonlarına dönüştürülmez.

`previous_locale_077170`, unsigned start/position karşılaştırmasını, multibyte-enabled DWORD'unu, geriye lead-byte/parite taramasını ve normal dönüşte PTD+0x3a8 bit1 temizliğini korur. NULL input errno22/invalid yoludur; start>=position NULL döndürür. `_LocaleUpdate` provider'ı hâlâ zorunludur. `select_code_page_region`, arama gövdesindeki inline bölgeyi çıkarır: locale65001 önceliği; aksi halde full EAX `066c1c` sonucu sıfırsa1, değilse0; ardından normal locale temizliği. Bu helper ayrı bir özgün fonksiyon sayılmaz.

`SupportEffects`, previous-character ve codepage bölgesini bu kaynaklara, sıralamayı gerçek `qsort_0768f0` ve slot-adresi karşılaştırıcısına bağlar. Özgün `06e41c` karşılaştırıcısının18 byte'ı dosyadan bounded okuma ve offline disassembly ile ayrıca doğrulandı. RCX/RDX adreslerini unsigned karşılaştırır; string içeriğini okumaz. Sıralama testlerinde12 dosyalık grup dahil genel partition algoritması çalışır ve byte yazmaz; sonuçlar enumeration fixture sırasını korur. Alfabetik sıralama eklenmedi. Byte kanıtı REA Evidence kaydı olarak sunulmaz.

`first_wildcard`, bu çağrıdaki sabit `*?` kümesi için sınırlı bytewise semantik bağlayıcıdır. `076da0` yordamının SIMD/CPU dalları, speculative okumaları ve instruction footprint'i burada yeniden kurulmaz. DBCS byte'ları wildcard aramasında byte olarak değerlendirilir; path geriye yürüyüşü ayrı gerçek multibyte kaynağını kullanır.

`./build.ps1` **4.010 ortak kontrolü** geçti. Actual configure mode2→expand→search→append→qsort/previous/codepage akışı kullanılır. Quote/parser bağımlılığı da gerçek kaynak gövdesidir. UTF8 önceliği ve ANSI/OEM numeric seçimi, unsorted12 dosya + prefix'li grup, dot/dotdot, eşleşmeyen literal, final NULL, calloc/recalloc hata12 ve final tahsis sonucu-1 test edilir. Hatalı yeniden configure eski argv/argc sahipliğini korur. Ayrıca NULL output ve unsupported NULL input, DBCS parity, empty argv ve final kopya hatasında output yayımlanmaması kontrol edilir.

Testte gerçek dosyalar aranmaz. Find kayıtları/handle'lar ve ASCII dönüşümleri sentetiktir. Recalloc provider'ı, actual recovered calloc/free ile kontrollü copy-and-replace fixture'ıdır; `070434` iç gövdesinin yeniden kurulması değildir. Locale provider'ı sabit canlı token/cell kullanır; native locale kurucusu veya gerçek PTD/FLS yürütmez. Fatal copy testindeki dört canlı allocation, kaynakta ek cleanup olmadığını gösterir; fixture sahibi sonunda kendi test belleğini bırakır. Bütün yolun native/SEH/ABI eşdeğerliği kanıtlanmadı.

`review-sort.json` üretim gövdelerini; `review-integration.json` mevcut test/source hashlerini inceler. Gerçek find/conversion/recalloc/locale sağlayıcıları, tam loader/export ve bağımsız DLL linkleme açık kalır. Özgün/yeniden derlenen DLL veya oyun yüklenmedi/çalıştırılmadı; orijinal dosyalar değiştirilmedi.

Sonraki heap aşamasında `../anadius-crt-recalloc-bridge-source` gerçek malloc/realloc/msize/recalloc gövdelerini wildcard ve onexit akışlarına aynı heap state üzerinden bağladı;5.483 ortak kontrol geçti. Bu klasörün eski bağımsız testi/validation kaydı kendi sağlayıcısını kullanmayı sürdürür. Yeni bileşimde recalloc artık kopyala/free compatibility fixture değildir; alt Heap API sağlayıcıları sentetiktir ve gerçek Windows/SEH/ABI eşdeğerliği açık kalır.
Sonraki dönüşüm aşamasında `../anadius-crt-conversion-bridge-source`, wildcard dönüşümlerini gerçek06004c/06e430 tampon,06ccc8/06cd58 API politikası,066c1c resolver ve heap/error kaynaklarına bağladı;7.440 ortak kontrol geçti. Bu klasörün önceki bağımsız testindeki conversion fixture korunur; yeni bileşimde bu yüksek seviye taklit metot kullanılmaz. Alt native dönüşüm yalnız ASCII fixture; gerçek Windows Unicode/locale/find/Heap API ve tam DLL/SEH eşdeğerliği açık kalır.
