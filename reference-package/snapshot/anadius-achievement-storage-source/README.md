# Achievement XML yükleme ve Watcher INI bağlantısı

`Storage::update_01eb00`, mevcut yapılandırma state'inin achievement kalıcılık normal akışını kurar. Set adı doluysa `user_directory/achievement-<set>.xml` yolu yeniden hesaplanır; set adı boşsa önceki XML yolu korunur ve doluysa yine okunur. Gerçek `03b3f0` dosya okuyucusu ve zorunlu XML backend kullanılır. Dokümanın error durumuna bakılır; parser return code'u ayrıca guard yapılmaz. Root veya çocuk tag adları doğrulanmaz: ilk element'in doğrudan element çocukları gezilir.

Id özniteliği olmayan kayıt atlanır; mevcut boş Id geçerli map anahtarıdır. Bilinmeyen Id için total1/count0/progress0, `0000-00-00T00:00:00` timestamp ve boş isim/SteamId ile kayıt eklenir. Count ve Progress her XML kaydında güncellenir; eksik veya dönüştürülemeyen değer0 olur. Grant mevcutsa boş olsa bile timestamp'i değiştirir. Name yalnız mevcut display_name boşsa okunur; CFG'den gelen dolu isim korunur. XML total veya SteamId alanı okumaz. Aynı Id tekrar geldiğinde bu kurallar sırayla uygulanır.

`attribute_003b70`, `006190` prefix seçimini korur: high-bit olmayan CRT whitespace sonrasında0x/0X varsa `%x`, aksi halde **`%d`** kullanılır; tarayıcıya orijinal string verilir. Çıktının32bit deseni Count/Progress alanlarına signed olarak taşınır. `%u` kullanımı doğru değildir. `Numbers` zorunlu bir sözleşmedir. `HostCrtNumbers` açıkça seçilen mevcut C runtime uyumluluk backend'idir; özgün statik CRT/locale/overflow/fault eşitliği değildir. Testler taşma dışında kalan normal decimal/hex alanlarını kullanır. CRT kurtarma kaynakları değiştirilmez.

SteamAppId doluysa dönüşüm sırası `achievements.ini`, app id, `achievement_watcher` olur; INI yolu user_directory altında kurulur. Bütün map kayıtları anahtar sırasıyla zorunlu `timestamp_to_epoch_041e10` sınırından geçer ve field70'e atanır. Ardından status(path,3) çağrılır. `error!=0 && ((uint32(kind)-1)&0xfffffff7)!=0` ise filesystem error yayılır. Kind2 ise mevcut dosya korunur; diğer kind sonuçlarında gerçek `achievement_writer::write_ini_01f9a0` kaynağı çağrılır. SteamAppId boşsa önceki INI yolu/field70 değerleri korunur ve status/writer çağrılmaz.

`Paths` iki kalıcı global yol hücresinin caller-owned karşılığıdır; başlangıç değerleri tahmin edilmez. `Effects` encoding, timestamp dönüşümü, status, filesystem error ve mkdir sınırlarını zorunlu tutar. Timestamp içindeki STL/locale/get_time gövdesi bu aşamada tamamlandı sayılmaz. `ConfigurationDependencies`, yalnız `update_achievement_storage_01eb00` metodunu Storage'a bağlar; diğer configuration metotları abstract kalır. Bu bağımlılık yeni config_startup initializer'ına verildiğinde gerçek XML yüklemesi ve INI kararı, profil devamında environment çağrılarından önce yürür.

Testler mevcut `xml_reader_bridge::Backend` ve sabitlenmiş TinyXML2 uyumluluk kaynağını kullanır. Özgün XML sürümü ve tüm bozuk girdi eşitliği kanıtlanmış değildir. `parse_c_string` ilk NUL'da durur. NativeFactory testleri yalnız kendi üretilen XML/INI dosyalarını okur/yazar; gerçek kullanıcı CFG, achievement dosyaları veya token okunmaz. Özgün DLL/oyun çalıştırılmaz. OS ve timestamp etkileri kontrollüdür; native allocator/layout/fault/SEH ve tüm DLL eşdeğerliği açık kalır.

Derleme `build.ps1` ile C++20/LLVM-MinGW `-O2 -Wall -Wextra -Werror`; ortak proje `../source-workspace/build.ps1`. CMake tanımı sunulur ancak bu teslimde ayrıca çalıştırılmış sayılmaz. `evidence.json`, `storage-audit.md/json`, `review.md/json`, `validation.json` ve `common-validation.json` adresleri, sınırlamaları ve doğrulanan kaynağı kaydeder.
