# Windows NLS API bağlantısı

Bu modül yeni yazılmış bir SDK bağlantısıdır; DLL'den çıkarılmış yeni fonksiyon gövdesi sayısı **0**. Önceki `06e210`, `06ccc8`, `06cd58` ve multibyte üretici kaynaklarının native CP/dönüşüm/tür API sınırlarını gerçek Windows importlarına bağlar. `Api` tablosunun her alanı SDK fonksiyonunun `decltype` türünü taşır; `Calls` varsayılan olarak `native_api()` kullanır. Testler aynı çağrı imzalı `WINAPI` fonksiyonlarını enjekte edebilir.

`GetACP`, `GetOEMCP`, `IsValidCodePage`, `GetCPInfo`, `MultiByteToWideChar`, `WideCharToMultiByte`, `GetStringTypeW`, `GetLastError` ve `SetLastError` kapsam içindedir. LCMap/locale-name çözümleme, scratch, atomik ve DLL giriş noktaları ayrı katmanlardır.

İzlenen çıktı hücrelerine ait destination değeri opak bir belirteçtir. NULL destination 0 değeri native çağrıya NULL olarak geçirilir; enjekte edilmiş API bu geçersiz çıktı adresiyle başarı döndürürse hücreler tanımsızlaştırılır ve domain_error üretilir. Bu değer native pointer'a çevrilmez. Pozitif kapasiteli byte dönüşümü gerçek `CHAR` tamponuna, pozitif uzunluklu tür sınıflandırması gerçek `WORD` tamponuna yazılır. Başarıda yalnızca API'nin tanımladığı hücreler işaretlenir. Byte sorgusunda kapasite 0 ise hücreler korunur. Hata halinde API'nin değiştirmiş olabileceği aralık tanımsız hücrelere dönüştürülür; önceki başarılı sonuçlar taşınmaz. API'nin kapasiteden büyük başarılı byte sayısı bildirmesi açık `domain_error` üretir.

Boş izlenen span doğrudan native yoludur: destination gerçek adres, kaynak gerçek adres ve signed uzunluklar değiştirilmeden geçirilir. Bu nedenle negative count/null-terminated native sözleşmesi bu yolda korunur. İzlenen WORD yolunun alanı yalnızca `0 < count <= cells.size()` değerleridir; negatif uzunluğu tahmin etmek için kaynak taranmaz. İzlenen byte yolu `0 <= capacity <= cells.size()` gerektirir. Kaynak, default-char ve used-default pointer'ları geçerli native bellek olmalıdır. İzlenen destination belirteci native kaynağın alias'ı olarak kullanılamaz. Gerçek adreslerin ömrü, sınırları ve çakışmaları çağıranın sorumluluğundadır.

Tam 32-bit BOOL sonucu korunur. `CPInfo`, SDK `CPINFO` yapısının yerine cast edilmez; başarılı çağrıda yalnızca tüketilen `MaxCharSize` ve 12 `LeadByte` baytı kopyalanır. Başarısız çağrı önceki `CPInfo` değerini korur. Staging ayırmasından önce gelen LastError saklanır, API'den hemen önce geri kurulur; çağrıdan hemen sonra alınan LastError, commit ve geçici tampon yıkımından sonra geri kurulur. C++ allocation failure, SEH veya asenkron/native yeniden giriş davranışları orijinal CRT eşdeğerliği olarak ileri sürülmez.

`build.ps1`: Clang 23.1.3, C++20, `-O2 -Wall -Wextra -Werror`; bağımsız nesne ve statik test EXE'si. Son doğrulama **143 kontrol**: SDK imzalı sentetik API fonksiyonları, opak destination, tam BOOL, CPInfo hata koruması, exact-count commit, tanımsız hata çıktısı, ham negatif uzunluk, query, kapasite hataları, LastError; ayrıca yalnızca sentetik UTF-8/UTF-16 dizgiler üzerinde gerçek Windows dönüşüm/tür çağrıları ve CP bilgisi. Orijinal DLL/oyun çalıştırılmaz; dosya, registry, hook, thread veya profil erişimi yoktur.

SDK sözleşmeleri: [GetStringTypeW](https://learn.microsoft.com/en-us/windows/win32/api/stringapiset/nf-stringapiset-getstringtypew), [WideCharToMultiByte](https://learn.microsoft.com/en-us/windows/win32/api/stringapiset/nf-stringapiset-widechartomultibyte). Bunlar yeni bağlantının API sözleşmesini destekler; binary gövdelerinin kanıtı önceki kaynak modüllerinde saklıdır. `evidence.json` ve `provenance.json` bu ayrımı kaydeder.
