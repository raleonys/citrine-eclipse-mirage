# Config2 yükleyicisini bootstrap başlangıcına bağlama

`config_startup::BootstrapConfiguration`, mevcut `BootstrapDependencies` arayüzünün üç uygulama metodunu gerçek kaynaklara bağlayan kısmi abstract sınıftır: `setup_environment_019910`, `setup_console_038760`, `load_configuration_01c870`. Diğer bootstrap metotları zorunlu kalır; worker/CRT/log/engine/global işlemler için sahte başarılı üretim gövdesi eklenmez. CRT üretim kaynakları değiştirilmez.

Komut satırı katmanının language/registry bayrakları ve `game_attributes` haritası, constructor'a verilen **aynı configuration::State** içinden alınır. Dışarıdan farklı map/flag alias'ı verilemez. Konsolun üç bayrağı ayrı zorunlu referanslardır. InputPlatform ve ConsolePlatform caller tarafından sağlanır; gerçek kullanıcı komut satırı, getenv veya konsol bu testlerde okunmaz/çağrılmaz.

`FilePass`, yeni `config_application::load_and_apply` akışını `configuration::ConfigurationPass` kaynak arayüzüne bağlar. `configuration::initialize_configuration(state,deps,pass)` önce executable yolunu alır, base ve override geçişlerini bu loader ile yapar, sonra **tek mevcut** profil/avatar/SDK/persistence/environment gövdesini yürütür. Önceki iki argümanlı initializer, DocumentPass ile eski `Dependencies::load_document` sözleşmesini kullanmaya devam eder. Bu refactor için yalnız configuration.hpp/.cpp değişti; post-configuration gövdesi çoğaltılmadı.

Bu bridge'i kullanan gerçek `Bootstrap::initialize` artık ortam/argüman → konsol → başlangıç log'u → executable/base/override → kullanıcı yolları/avatar/cleanup → sürüm/SDK → achievement persistence → ContentId/EAGameLocale ortam çağrıları → ilk worker sırasını izler. Base/override hatası ilk worker'a ulaşmayı engeller; önceki değişiklikler geri alınmaz. Başarısız environment BOOL sonuçları özgün kaynakta olduğu gibi göz ardı edilir. Komut satırı dil kilidi iki Config2 geçişinde aynı State üzerinden gözlenir.

Bu bir kaynak bileşimidir; native DLL export/DllMain/loader ve bütün global kurulumu değildir. Bridge hâlâ somut bağımlılık sahibi tarafından instantiate edilmelidir. Asıl worker'lar, CRT thread wrapper, native konsol FILE sınırları, path/locale sağlayıcıları ve persistence iç kodu ayrıca bağlanmalıdır. `Dependencies::directory_entries` toplu vector verdiğinden, native iterator'ın silmelerle iç içe ilerlemesi veya ortadaki OS hata zamanı bu modelle eşdeğer sayılmaz. MSVC allocation/layout/exception/SEH ve native fault zamanlaması kanıtlanmamıştır.

`build.ps1` C++20/LLVM-MinGW ile yalnız kendi test programını derler. Testler controlled OS/console/environment/worker bağımlılıkları, sentetik memory stream'ler ve kendi üretilen fixture dosyalarını kullanır. Gerçek kullanıcı CFG/token içeriği okunmaz, özgün DLL/oyun çalıştırılmaz veya değiştirilmez. CMake tanımı sunulur; doğrulanan yol PowerShell derlemesidir. Ortak proje `../source-workspace/build.ps1` içindedir.

Adresler, REA kanıt kimlikleri ve sıralama sınırları `startup-audit.md/json`; kaynak ve kapsam kaydı `evidence.json`; bağımsız inceleme `review.md/json`; derleme sonucu `validation.json` ve `common-validation.json` dosyalarında tutulur. Kaynak arayüzleri özgün DLL'nin virtual class düzeni sayılmaz. Yeni benzersiz özgün yordam sayısı0; daha önce kurtarılan01c870/038970/019910/038760/019ad0 kaynakları birleştirilir.
