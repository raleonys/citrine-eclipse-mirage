# Achievement runtime: bağımsız kaynak incelemesi

Sonuç: **PASS — incelenen normal akış ve açık kaynak sözleşmelerinde maddi bulgu yok.** İnceleyen: `achievement_runtime_audit`. Bu kayıt, ana ajanın yazdığı dört üretim dosyasının bağımsız statik incelemesidir; test çalıştırma veya binary differential kanıtı değildir. İncelenen dosyaların SHA-256 değerleri eşlik eden JSON'dadır. Sonraki değişiklikler bu incelemeye otomatik dahil değildir.

İncelenen dosyalar: `outputs/anadius-achievement-runtime-source/utc.hpp`, `utc.cpp`, `runtime.hpp`, `runtime.cpp`. Dayanak: `achievement-runtime-audit.md/json` ve orada tanımlı retained assembly/pseudocode.

- `utc_time_041b60`: önce bir `time_05eeb8`, ham sonuç ne olursa olsun bir `gmtime_05fffc` çağrısı vardır. Optional value dönüşü dokuz `BrokenDown` alanının kendi kopyasıdır; native `041bbb..041bcd` snapshot'ına karşılık gelir. Nullopt durumunda yalnız optional epoch sıfırlanır ve boş string döner; formatter çağrılmaz (`041dc6..041de0`).
- Başarı durumunda optional epoch gerçek `calendar_recovered::epoch_041ff0` kaynağıyla tekrar hesaplanıp uint64 bitlerine taşınır; ham clock değeri kullanılmaz. Bu atama formatter'dan önce yapılır (`041bd9..041bde`). Mode API'si uint8 olup sıfır/nonzero seçimi `041ca2..041ca5` ile eşleşir. Formatter string'i olduğu gibi döndürülür; empty/partial/embedded-NUL için ek başarı kapısı yoktur. İstisnalar yutulmaz.
- `HostClock`, `std::time` ve `_gmtime64_s` seçilmiş host-runtime uyumluluk uygulamasıdır. `_gmtime64_s` kullanımı native `_gmtime64` ABI'si kurtarılmış iddiası değildir; yerel tm alanları açıkça kopyalanır. `HostFormatter`, alanları host tm'ye koyar, mevcut global C++ locale ile `std::put_time` kullanır ve `stream.str()` üzerinden açık uzunluğu korur. Genel native CRT/time_put, locale, allocation ve exception eşitliği açıkça kapsam dışıdır.
- Output document, mevcut `MemoryPrinter` ve `HandlerWriter` kaynaklarını gerçek olarak birleştirir. `c_string_without_nul` native CStr/strlen yoluyla uyumlu ilk NUL'e kadar alır; `041b60` stringbuf yolunun explicit-length davranışından farklı tutulmuştur. Output-only reader'ın beklenmeyen request okuması açık logic_error üretir; sessiz başarılı boş provider yoktur. Document bileşenlerinin kurulum sırası referansların ömrünü korur.
- `PersistenceEffects` yalnız tarih/printer/XML/INI metotlarını final uygular; diğer içerik/avatar/provider metotları abstract kalır. XML yazımı gerçek `write_binary_03c1d0` üzerinden BOOL sonucu yoksayar; native `030ac1` çağrı sitesine uygundur. INI için gerçek `write_ini_01f9a0` kullanılır. Native tek global map kimliği, caller-owned State map'iyle korunur; farklı map yeni açık kaynak alan denetimiyle invalid_argument üretir. Bu guard özgün ayrı bir yordam veya native exception davranışı sayılmaz.
- `bind_state`, content/entitlement vektör span'larını, game/achievement map'lerini, set/content/user kimliklerini, XML path'i ve avatar/user-directory alanlarını doğru State/Paths hücrelerine bağlar. Online byte, saved-avatar count, mutex/event queue yaşamı caller'a aittir. Başvurulan caller-owned nesneler veya vektör storage'ı view kullanılırken yaşamını/yerini korumalıdır; kaynak bu sorumluluğu belgeler.

Mevcut grant çekirdeğiyle birleşimde XML öncesi completion-event, XML sonrası INI ve en son response sırasını sağlayan kod `content_handlers.cpp` içindedir; yeni bridge bunu yeniden düzenlemez veya başka kilit eklemez. Başlangıç mutex/event global kurulumu ve bütün native concurrency/SEH/ABI eşitliği bu PASS'ten çıkmaz. Testler ayrı worker/ortak build tarafından doğrulanmalıdır.
