# Config2 hash/list büyümesi ve kopya kapasitesi

`hash_table.cpp`, önceki sekiz anahtarla sınırlı order modülüne ek olarak gerçek büyüme ve kopya geçmişini mantıksal kaynak modelinde taşır. Önceki modül değiştirilmedi. Bu model özgün DLL kodunu çağırmaz; container düzeni, string/node allocator, exception/SEH ABI'si veya bütün DLL eşdeğerliği iddia etmez. Tam yeni özgün yordam sayımı **0**: burada adresle desteklenen algoritma parçalarının normal yol bileşimi vardır.

`Table` kendi `bucket_count` ve özgün list dolaşımını tutar. Hash, byte uzunluğunu kullanan unsigned FNV1a64'tür; embedded NUL veri olarak kalır. Mevcut unique key lookup'u kaydı taşımadan döner. Yeni key boş bucket'ta sona, dolu bucket'ta ilk kaydın önüne eklenir. Host `std::unordered_map` dolaşımı kullanılmaz.

`017440`, load factor1 için binary32 `ceil(float(size)/1.0)` ve minimum8 kullanır. Mevcut kapasite yeterliyse korunur. Kapasite512'den küçük ve gereken sayı mevcut kapasitenin sekiz katına sığıyorsa sekiz kat seçilir. `017570` isteği yukarı doğru ikinin kuvvetine yuvarlar, her bucket'ın unique-key grubunu source-list'teki ilk görünüm sırasına göre yerleştirip grubun iç sırasını ters çevirir. Tek tek eklemede sınırlar8→9 için64,64→65 için512,512→513 için1024,1024→1025 için2048'dir.

Bulk kopya farklıdır:65 satırlı parse container'ı incremental büyümeyle512 bucket taşıyabilir; **fresh root assignment** `017440(8,65)`→65, `017570`→128 bucket seçer. Yeni **descendant clone** ise source'ın512 kapasitesini miras alıp source list'inden yeniden insert yapar. Bu yüzden root ve descendant kopyalarını aynı "fresh8" yordamıyla modellemek doğru değildir.

`Table::assign_from` hedefin önceki kapasitesini tutar ve sayı değişmese de rehash yapar. `Table::clone` source kapasitesini miras alıp yeniden insert eder. Self assignment, özgün `0162f0` self guard gibi rehash yapmaz. `growth_target` ve `rounded_buckets` aritmetiği native size sınırı`0x1745d1745d1745d` ve bucket hedef sınırı`2^59` ile sınırlar; modelde bu büyüklükte storage ayrıldığı iddia edilmez. rounded_buckets, gözlenen minimum8 çağrı domaininin altını mantıksal validation hatasıyla reddeder; bu özgün017570 için error davranışı iddiası değildir. Host allocation/length hatalarının native fault sınıfı, zamanı veya kısmi mutation durumu eşdeğer değildir. Modelde gözlenen factor1 sabittir; harici factor mutation alanı sunulmaz.

`Node` child map'i yalnız lookup depolamasıdır; traversal her zaman `Table::traversal` ile belirlenir. `Node::assign_from`, **hedefin eski list pozisyonlarını source'ın eski list pozisyonlarıyla** eşler; key değişse bile mevcut row payload'unun descendant tabloları recursively assign edilir ve eski kapasiteleri kalır. Source'ın fazladan satırları recursively clone edilir; hedefin fazla tail satırları silinir. Parent table ancak bu işlemden sonra rehash olur. Böylece farklı ada dönüşen aynı pozisyonun eski512 bucket'lı child table'ı korunabilir. Bu, section destination tekrar kullanıldığında AchievementNames gibi alt tabloların sırasını etkiler.

`Node::lookup` eksik outer key'i ekler; yeni inner name/value boş, child table fresh8'dir (`012820`). `from_parser` parser'ın first-created unique slot sırasını yeniden insert eder; tamamlanan duplicate assignment parent list kaydını taşımaz ve replacement subtree parser'da zaten son tamamlanan değer olarak tutulur. `selected_copy` **önceden seçilmiş mantıksal Config2 node'unu** fresh hedefe assign eder. `to_configuration` sahip olunan configuration node döndürür. Assign source ile destination ayrık owned ağaçlar veya aynı nesne olmalıdır; bir ağacın kendi descendant'ından örtüşen assignment bu kullanımdan ve kanıttan çıkarılmamıştır.

PowerShell `build.ps1`, LLVM-MinGW C++20 `-O2 -Wall -Wextra -Werror` ile üretim nesnesi ve test exe'sini derler. **4.929 kontrol PASS**:1100 insertion üzerinde bağımsız `std::list::splice` oracle; growth sınırları; binary32 büyük-count yuvarlama; fresh/reused/self assignment; recursive positional reuse;720 permütasyonda eski bounded modülle differential; unsigned/NUL hash ve65-row root128/descendant512 ayrımı. Sentetik byte/key girdileri kullanıldı. Kullanıcı CFG/token dosyası okunmadı; özgün DLL veya oyun çalıştırılmadı/değiştirilmedi. CMake tarifi vardır; bu teslimde doğrulanan komut PowerShell build'idir.

`evidence.json` adresler ve REA Evidence kimliklerini, `evidence.asm.txt` ve `evidence.pseudo.c.txt` mevcut immutable listing'lerden seçilmiş15yordamın tam pasajlarını içerir. Bu modül daha sonraki section lookup/kopya çağrı zaman çizelgesini kendisi tahmin etmez; consumer adapter bu API üzerinden gerçek sırayı kurmalıdır.
