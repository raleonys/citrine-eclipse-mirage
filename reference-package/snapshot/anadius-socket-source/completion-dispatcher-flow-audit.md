## Gate, service collection, and queue publication

Entry `027c39..027c4d` caches the **address of the native TLS vector slot**, computed from GS:[58] and the current native TLS index `A47E8`, before any loop/SDK call. This is distinct from the public `TlsGetValue` slot used by the outer worker run loop. `027c51..027c58` retains the address identity of scheduler port field `+28`; SDK calls read the live handle through that address. R15 starts as one. The loop starts with RBX zero (`027c62`). At `027c70..027c78`, locked compare-exchange at scheduler `+58` changes exactly expected one to zero; any other prior value skips collection.

On successful collection gate, enter the critical section at scheduler `+60` (`027c89`) and hold it through collection, publication, timer processing and any remaining direct cleanup callbacks. No native normal-body exception-unwind behavior is established. Local queue head/tail start zero (`027c96..027c99`). Read scheduler `+90` head; only if head is nonnull, detach both scheduler head/tail and copy both to the local queue (`027c9e..027cc0`). A nonnull scheduler tail with null head is not cleared by this body.

Traverse scheduler service head `+88` (`027cc7`). Invoke each service virtual slot `+20` with the address of the local head/tail queue (`027cd3..027cdd`). Read that service's `+8` next link **after the callback** (`027ce0`), so live mutations are observable. The later timer traversal is separate and reloads scheduler service head.

For each local operation (`027d00..027d1b`), pop the live `+20` next link first, clear local tail only if new head null, clear popped operation next, and store queued flag `+30` as one. Then post `(live port, bytes=0, key=0, popped operation)` (`027d1f..027d2b`). On post success continue with live local head. Failure does not read GetLastError: enter the same critical section **recursively** (`027d38`), append the failed operation to the live scheduler queue, append the remaining local chain after it, transfer the local tail, clear local head/tail when that remainder exists, exchange scheduler collection flag `+58` to one, leave only the recursive acquisition (`027d3e..027d8e`). The outer acquisition remains held until `027e8c`. Read queue head after callbacks rather than using a precomputed list snapshot. The failed operation's queued flag remains one.

## Timer and residual cleanup

If scheduler timer indicator `+48` is nonzero (`027db3`) and live service head nonnull (`027dbf`), start timeout accumulator at signed 300000000. Each service slot `+18` receives the current signed accumulator and returns the next (`027dd0..027ddb`). Read next link after the callback (`027ddd`). There is no independent minimum operation in dispatcher: each service controls its returned accumulator. Compare final signed int32 result with 300000000 (`027de6..027deb`). For smaller values, compute NEG **in 32-bit wrapping arithmetic** at `027ded`, sign-extend the resulting int32 (`027def`), then multiply int64 by ten (`027df2..027df6`). This differs from mathematical `-int64(value)*10` for INT32_MIN. Call SetWaitableTimer with live handle `scheduler+50`, due value, period 300000, null callback/argument, resume false (`027dfd..027e17`). Ignore BOOL and do not read last error.

Any local operations still present are popped live and detached, then their completion function at `+28` is called `(owner=null, operation, Error{0, generic A10F8}, bytes=0)` (`027e40..027e6f`). This path does not set queued flag or decrement work count. The ordinary publication loop consumes/requeues the chain; retaining this cleanup loop still preserves the full native body. Then leave the outer critical section (`027e84..027e8c`).

## Completion wait and operation dispatch

Before every GetQueuedCompletionStatus call zero bytes, key, and operation outputs (`027e92..027e99`); call SetLastError(0) (`027e9d..027e9f`); only then read scheduler `+40` and calculate unsigned min with the original timeout argument (`027ea5..027eaf`). Read port live at wait call (`027ebf`). Cache BOOL, and call GetLastError **unconditionally**, even BOOL success (`027ec9..027ed2`). No extra last-error read is allowed on operation or timeout paths.

For a nonnull operation, read the live pointee of the cached native TLS slot, then signed epoch at pointee `+4` (`027ee6..027eed`). If signed global guard `A38E8` is greater (`027ef0..027ef6`), call required `04b838` on that guard; reload guard after the call, and only if -1 register opaque exit callback identity `07dff0` via `04b770`, then call `04b7cc` (`028092..0280be`). Ignore atexit return. Continue at metadata selection, without repeating GQCS or the epoch check (`0280c3`). The CRT providers remain required and unchanged.

Start local logical error with cached GetLastError and static category identity A1110 (`027efc..027f06`), **without calling system_category_028620**. For key exactly 2, use operation category at `+0`, value `+10`, and byte count `+14`, preserving operation metadata (`027f11..027f2d`). Otherwise write A1110, cached status and GQCS bytes into those three operation fields (`027f32..027f3e`). Metadata handling happens before the queued-state test.

Locked compare-exchange at operation `+30` attempts zero to one (`027f41..027f43`), but callback is invoked **only when the previous value equals one** (`027f49..027f4c`). Previous zero publishes one and restarts the dispatcher; all other values remain unchanged and restart. This is intentionally not a normal claim-success CAS branch. On previous one, overwrite the local TLS-slot-pointer stack variable with scheduler identity (`027f52`), then call operation callback with `(scheduler, operation, selected error, selected bytes)` (`027f56..027f68`). Native callback may free the operation: no operation field access occurs afterward.

After callback, inspect state `+50` as **signed int32** (`027f71..027f75`). Values <=0 write success logical result `{0, A10F8}`, perform locked low32 work count decrement at scheduler `+30`, and if prior count exactly one call actual recovered `02a190` (`027f7b..027faa`). Result is written before decrement/stop; exceptions from stop cannot undo it. Return uint64 one (`027fb0`). Native 32-bit status padding is unspecified, excluded from logical Error.

Positive pending count is cleared before copying pending exception context. `028076` calls `024100(dst1,state+58)`, `028084` calls `024100(dst2,dst1)`, then `02808c` calls `029880(dst2)`. Each `024100` zeroes its two qword destination fields before calling __ExceptionPtrCopy and returns destination identity. `029880` is a **terminal boundary**: its entire assembly calls `04a2d4` and executes INT3; there is no RET or epilogue. Thus no normal fallthrough from this rethrow boundary into guard initialization can be asserted. The next assembled guard block is physically contiguous, but normal return is not established. Required providers must preserve this terminal contract; no native exception/refcount/SEH semantics or unwinding are recovered by this stage. The overwritten TLS-slot variable has no later normal read after a callback because the normal branch returns and the pending branch is terminal.

## Null operation, timeout, and stop relay

BOOL failure plus null operation: cached error 0x102 and original timeout INFINITE restarts (`027fbd..027fc9`). Error 0x102 with any finite original timeout writes generic success and returns zero, irrespective of scheduler wait cap (`027fcf..027fd7`). Every other cached error calls system_category_028620, including zero error, writes cached value/category and returns zero (`02802d..028054`). Preserve cached error across the category callback.

BOOL success plus null operation and key exactly one jumps directly to gate retry (`027fd9..027fe3`), without wake/stop exchanges. Other keys exchange low32 wake `+38` to zero, then locked fetch-add zero reads low32 stop `+34` (`027fe9..027ff0`). If stop zero, retry gate. Otherwise exchange low32 wake `+38` to one and retain the prior wake in R15D (`027ffd`). Prior nonzero skips post; prior zero posts `(live port,0,0,null)` (`028006..028012`). Success writes generic success and returns zero. Failure caches a fresh GetLastError, calls system category even error zero, writes cached error/category and returns zero (`02801c..028054`). Upper wake qword bits are preserved; no flag rollback. Although R15D is overwritten by the last wake exchange, every path after it returns zero, so it does not change the next gate's expected-one behavior.
