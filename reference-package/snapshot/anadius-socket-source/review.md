# Socket kaynakları: bağımsız üretim kodu incelemesi

Sonuç: **PASS — tanımlanan normal kontrol ve provider domaininde maddi bulgu yok.** İnceleyen: `socket_ops_audit`. Dört üretim dosyası incelendi; bunların donmuş SHA-256 değerleri JSON'dadır. Bu inceleme test çalıştırma, gerçek network yürütmesi veya runtime binary differential kanıtı değildir.

İncelenen dosyalar: `outputs/anadius-socket-source/operations.hpp`, `operations.cpp`, `native.hpp`, `native.cpp`. Dayanak: eşlik eden `socket-ops-flow-audit.md/json` ve oradaki retained REA Evidence/adresleri. Yeni normal kaynak yordamları028690 ve02a200'dür; SDK adapter ve partial ServerBackend/Transport köprüleri ayrıca keşfedilmiş özgün gövdeler değildir. Kategori getter028620 internalleri zorunlu provider olarak kalır; CRT kaynakları yeniden yazılmaz.

- Adres çekirdeği, WSASetLastError0 çağrısını family denetiminden önce yapar; yalnız2/23 kabul eder. C string öneki/capacity hesabı ve signed kapasite dışındaki açık domain hatası belgelenen sınırdır. Conversion.result kontrol edilmeden string_to_address çağrılır. Kategori getter → LastError sırası korunur; native getter'ın lazy etkileri atlanmaz. Non−1 parse sonucu başarıdır; IPv4 ilk4, IPv6 tüm16 ve optional scope yazımı ile başarı error0 doğrudur.
- Broadcast failure dalı yalnız ilk4 baytaFF yazar, sonra hata10022 ve−1 üretir. Öteki failure hedefleri korunur, error0 fallback10022'dir. Native return-register üst32bit farkı, error padding ve stack allocation modeli açık domain dışında bırakılmıştır.
- Send çekirdeği invalidsocket10009 dalını empty shortcut'tan önce alır. all_empty&&state16 yalnız error.value0 yapar. Her send sonrası kategori getter/LastError ve64→10054,1234→10061 map çağrıları native sıradadır. Status0 error0 ve signed32 transferred dönüşü; sign-bit durumunda failure koluna düşme; statebit1 erken0; opaque kategori **name-function identity** karşılaştırmaları ve bir/iki getter retry çağrısı korunur. Select nfds düşük32bit+1 wrap, fd/socket ve negatif-ham-hata / nonnegative-yeniden-dene akışları doğrudur. Yeni timeout veya retry limiti yoktur.
- `NativeApi` gerçek SDK WSABUF tipini kullanır. WSASend'e aynı span pointer'ı ve sayısı, sıfırdan başlatılan DWORD transferred, ham flags, null overlapped ve null completion gider. WSASend sonrası geçici vektör veya allocation destruction yoktur; doğrudan küçük SendCall döner. Böylece bu noktaya adapter-owned buffer cleanup eklenmemiştir. Select gerçek SDK fd_set count1 ile yalnız write set kullanır.
- Native wide conversion scratch'i heap'te ayırır ve yalnız positive/in-range/terminal-NUL çıktısını sahipli Conversion.text'e alır. Bu, native stack footprint/allocator veya conversion failure sonrası undefined scratch eşitliği değildir. Core conversion sonucunu yine yoksayar; NativeApi string_to_address ancak tanımlı NUL-terminated text ile çalışır, aksi durumda açık UnsupportedInput üretir. Bu guard özgün WSA hata sonucu sayılmaz.
- StringToAddressW caller-owned mutable Conversion.text üzerinde çağrılır; API dönüşü ile core kategori/LastError örneklemesi arasına ayrı wide-string kopyası destruction'ı eklenmez. API success sockaddr boyutu ve family domaini açıkça denetlenir; gerçek SDK sockaddr_in/in6 memcpy ile okunur, uyumsuz C++ struct alias cast'i kullanılmaz. Stack storage'ın sıfırlanması ve başarıda tanımlı output alanları seçilmiş backend domainidir; native başlatılmamış scratch/padding/partial malformed API output eşitliği değildir.
- Son donmuş native.cpp, Socket/SOCKET=64 bit, wchar_t=16 bit, DWORD=32 bit, AF_INET=2, AF_INET6=23, sizeof(sockaddr_storage)=128, sizeof(sockaddr_in)=16/adres offset4 ve sizeof(sockaddr_in6)=28/adres offset8/scope offset24 için compile-time SDK layout doğrulamaları içerir. Bu ekler çalışma zamanı davranışını değiştirmez; hash kaydı bu son sürüme bağlanmıştır.
- CategoryProvider zorunludur; NativeApi constructor WSAStartup veya başka socket işlemi çağırmaz. NativeApi kategori çağrılarını provider'a her native konumda iletir. Genel native guard/singleton/atexit/lifetime, bütün library allocation/post-call LastError footprint ve ABI eşitliği bu bridge'den çıkmaz.
- AddressBackend diğer ASIO/server etkilerini abstract bırakır. SynchronousTransport yalnız senkron gönderim metodunu uygular, canlı socket/state hücrelerini okur, tek gerçek WSABUF/flags0 ile recovered send çağırır ve mantıksal sonucu server WriteResult'a taşır. Native025720 bağının flags0 değeri bağımsız doğrulandı: `02574b XOR EBP,EBP` ve arada EBP yazımı olmadan `0258a4 [RSP+0x20]=EBP`; count1 `0258a8`, WSABUF `0258ae`, state/socket `0258b3/0258b7`, CALL02a200 `0258bb` konumlarındadır. Evidence ve all_empty bağı flow audit'tedir. Async receive/send ve ownership kaynakları tamamlanmış sayılmaz. DWORD dışı buffer boyutu açık destek sınırıdır.

Native category/name identity, WinSock/global başlangıç, IOCP/ASIO, socket yaşam süresi, native layout/padding/allocator/SEH/unwind/concurrency ve tam DLL eşitliği açık kalır. Gerçek socket/network testi bu incelemede yapılmadı; injected import testleri ayrıca doğrulanmalıdır. Önceki üretim dosyaları bu ajan tarafından değiştirilmedi.
