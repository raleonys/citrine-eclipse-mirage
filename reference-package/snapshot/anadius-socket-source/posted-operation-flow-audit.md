Altı normal gövdenin tamamı saklanan assembly ve pseudocode üzerinden bağımsız okundu. `anadius-all-functions.pseudo.c` SHA-256 `26fe3e2e2c6fe6459d39d8f3a95738b2f83bb7d6b333b61249bdc00abd1d5acb`, `anadius-all-functions.asm.txt` SHA-256 `9b8c894f85b1ca0fd090a95993ecd5048e59a41ae2459e2bbdc80215e8027a42` önceki baselinela eşleşiyor. Hedef DLL SHA-256 `9e420c3aae5ea26410f0bf578f86c47e51e36ff770b9e2a28b5eaee46aed786c`. Bu inceleme orijinali yürütmez; gerçek kullanıcı verisi veya yapılandırma içeriği okunmadı.

## Kritik sıra ve alias sınırları

- `0x180022e40`: allocation boyutu **0x48 (72)**, hizalama 1. İlk scheduler ve `scheduler+0x28` TLS anahtarı TLS çağrısından önce saklanır; publication scheduler'ı daha sonra executor üzerinden canlı okunur. İlk eşleşen TLS frame'in state alanı sıfırsa arama durur; daha sonraki eşleşme inline olamaz. Bit0 inline aramayı tamamen atlar. Allocator için ikinci TLS okuması yapılır ve global TLS index yeniden okunur. Entry executor adresinin düşük baytı allocation tag argümanı olarak saklanan ilk RCX'ten okunur; `021820` bu argümanı kullanmaz. Callback identity `0x180027120`, intrusive next, SDK alanları ve queued alanı başlatıldıktan sonra source functor taşınıp sıfırlanır; work count ancak publication yordamında artar. Bit1 üçüncü publication argümanına dönüştürülür fakat `028ca0` onu okumaz. Son normal cleanup frame +8/+10 sıfırdır.
- `0x180027120`: functor +0x38'den lokale taşınır ve object alanı sıfırlanır (`02713d..027146`). İlk gerçek `028fd0` çağrısı (`027153`) functor invocation'dan **önce** allocation'ı cache'e koyabilir veya serbest bırakabilir. Owner sıfır değilse consume helper; owner sıfırsa invocation yok, discard(flag0) var. Consume helper lokal slotu flag1 çağrısından önce sıfırlar. Sonra lokal tekrar okunur; callback onu doldurduysa flag0 çağrılır. İkinci cleanup yalnız normal dönüş akışında vardır; normal gövde exception unwind davranışını kanıtlamaz.
- `0x180028fd0`: object canlı okunur, object.functor varsa flag0 çağrılır; callback sonrasında frame.object koşulsuz sıfırlanır (`028ff7`). Allocation **bu callback sonrasında** frame +8'den okunup RBX'e saklanır (`028fff`). TLS getter/frame mutasyonları saklanan allocation'ı değiştirmez. Yalnız mevcut TLS frame'in state alanı kullanılır; zincir araması yoktur. İlk iki cache slotundan ilk boşuna marker `[allocation+0x48]` önce `[allocation]`'a taşınır, slot yazılır, frame.allocation sıfırlanır. Cache dolu/TLS yoksa saklanan allocation free edilir, free callback frame alanını değiştirse bile alan daha sonra sıfırlanır.
- `0x180021820`: unsigned64 sarılan `(requested+3)>>2` units; iki cache slotunda başlık baytı units kadar büyük ve raw adres modulo alignment sıfır olan ilk aday seçilir. **alignment0 yalnız diğer uygunluk koşulları geçmiş bir adayın DIV aşamasında native fault**; cache yoksa veya tüm adaylar küçükse modulo yapılmaz. Hit slotu header yeniden okunmadan ve `[allocation+requested]` yazılmadan önce sıfırlanır. Miss'te ilk dolu slot önce sıfırlanır, ardından free edilir; yalnız bir slot tahliye edilir. Allocation byte sayısı unsigned64 `units*4+1`; marker units<=255 ise düşük bayt, aksi halde 0. RCX/tag kullanılmıyor.

## Kanıt kapsamı ve açık sınırlar

Altı gövde normal akış olarak sayılır. `04b0bc` allocator ve `04b788` deallocator gövdeleri bu aşamada yeniden kazanılmış sayılmaz; gerekli providers olarak kalır. Functor slot00(flag1 invocation / flag0 discard), gerçek functor nesne yaşamı ve local-slot alias erişimi provider sorumluluğudur. Windows OVERLAPPED içeren typed object ile allocation/raw metadata ayrı tutulmalıdır; compiler vtable'ı native ABI yerine koyulamaz. Bounded storage guardları native invalid-memory/DIV fault davranışının modellenmiş `UnsupportedInput` sınırıdır; bunlar DLL'in gerçek exception türü veya cleanup sözleşmesi değildir. Native ABI, allocation provenance/lifetime, exception/SEH/unwind ve eşzamanlılık orijinal yürütülmeden kanıtlanmadı. CRT production değiştirilmedi. Tam DLL davranış eşdeğerliği veya tamamlanma iddiası yoktur.
