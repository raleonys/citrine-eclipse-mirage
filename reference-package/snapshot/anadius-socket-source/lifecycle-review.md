# Socket lifecycle kaynak incelemesi

Sonuç: **PASS — maddi bulgu yok.** Yalnız dondurulmuş dört üretim dosyası retained REA pseudocode/assembly sözleşmeleriyle karşılaştırıldı. İnceleyen üretim dosyalarını değiştirmedi; test EXE'si, özgün DLL/EXE veya ağ işlemi çalıştırmadı. Test sonuçları ayrı kayıtlardır.

İncelenenler: `outputs/anadius-socket-source/lifecycle.hpp`, `lifecycle.cpp`, `lifecycle_native.hpp`, `lifecycle_native.cpp`. Tam hash'leri JSON kaydındadır. Bağımsız akış ve Evidence ID'leri `socket-lifetime-flow-audit.md/json` içinde tutulur.

`initialize_0211b0` önce zorunlu service resolver'ını çağırır. Pair'i sıfırlaması eski owner yüklemesinden öncedir; önceki logical owner'a yanlış bir release eklenmez. Seçili protokol/state başlangıcı, opaque executor tablo kimlikleri/context/self-reference metadata'sı ve service'i metadata sonrasında yeniden saklama sırası korunur. Gate içinde next=head/previous=NULL, eski head.previous=self ve head=self yazımları native `02128b..0212a8` sırasını karşılar. Header, nesne adreslerine overlay veya native padding/ABI kurulduğunu ileri sürmez.

`replace_owner_0237f0` önce24 byte isteğiyle zorunlu factory'yi çağırır, yeni control varsa strong/weak=1 ve resource'u kurar. Pair.resource yazıldıktan sonra old control okunur, sonra yeni control yayımlanır. Böylece allocator/new-handler reentry sırasında değişen eski owner yanlışlıkla çağrı başından cache'lenmez. Eski resource callback'i yeni pair'i görür; callback'in pair üzerinde yaptığı değişiklikler tekrar ezilmez. Release, strong fetch_sub öncesi1 koşulunda destroy_resource; ancak bundan sonra weak fetch_sub öncesi1 koşulunda delete_control yapar. Weak sayısının callback'ten sonra okunması ve aynı eski control kimliği korunur. Atomik32bit işlemlere yeni underflow/saturation koşulu eklenmez.

`destroy_024db0`, service'i close/cancel provider'ından önce cache'ler ve aynı service gate/list'ini kullanır. Head/prev/next güncellemeleri, own links NULL yapılması ve gate leave, executor cleanup'tan öncedir. Executor metadata identity'si callback'e çağrı anında aktarılır; final control owner'ı cleanup'tan **sonra** yüklenir. Final release owner slotunu ayrıca NULL yapmaz. Bu kaynak C++ otomatik destructor'u gibi davranıp native akışa ek temizleme veya socket kapatma eklemez. `026fb0` içi zorunlu provider'dır;025310 ile sessizce ikame edilmez.

`LifecycleRuntime`, önceki AcceptorRuntime'un initialize/reset sınırlarını bu iki yeni gerçek kaynak gövdesine bağlar. Bound state kimliği doğrulanır; farklı state `UnsupportedInput` ile açık alan dışıdır. Category ve exception metodları soyut kalır. `destroy_socket_024db0` explicit çağrıdır; C++ wrapper destructor'u nesneyi kendiliğinden ikinci kez silmez. Service/object/control/provider ömürleri caller yükümlülüğüdür.

`NativeSocketGate`, caller-owned initialized SDK `CRITICAL_SECTION&` üzerinde yalnız EnterCriticalSection/LeaveCriticalSection imzalarıyla çağrı yapar. Enjekte importlar mümkündür; constructor hiçbir API çağırmaz, CS oluşturmaz veya silmez. Windows x64/LONG32 varsayımları static_assert ile kontrol edilir. Bu typed bağlayıcı native ASIO hizmet belleğinin layout'unu yeniden kurmaz.

`OwnedNoopControlFactory` açıkça seçilmiş host uyumluluk allocator'ıdır; `new(std::nothrow)` ve noop resource destruction kullanır. Caller'da gözlenen native24-byte isteği ile typed allocation object size/ABI veya gerçek04b0bc/new-handler/throw eşitliği karıştırılmaz. Native04b0bc exhaustion retry/throw davranışı yeniden yazılmış değildir. NULL caller dalının testi, özgün allocator'ın bu durumda gerçekten NULL döndüğünün kanıtı değildir.

Kalan sınırlar: service lookup/RTTI/lazy creation0239c0; cancellation/IOCP/socket close026fb0; executor cleanup etkileri; native allocator/control vtable/padding ABI; genel shared ownership/concurrency; CRT/new-handler/SEH/unwind; tüm DLL/runtime eşitliği. Kısa ömür, bozuk list, control callback'i sırasında kendi storage'ını erken yok etme ve constructor'ı linked node üzerinde tekrarlama geçerli native normal-flow sözleşmesi değildir. Bu inceleme gerçek ağ veya özgün hedefle runtime differential sağlamaz.
