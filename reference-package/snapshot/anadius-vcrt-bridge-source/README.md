# VCRT, ACRT ve dış CRT kaynak bileşimi

`bridge.cpp`, önceki dış CRT girişinin altı bağımlılık metodunu gerçek kurtarılmış CPU ve VCRT yaşam döngüsü gövdelerine bağlar. Bu yeni bir kaynak entegrasyonudur; ek bir özgün fonksiyon kurtarıldığı iddiası değildir. Kaynak hedefi anadius64.dll SHA-256 `9e420c3aae5ea26410f0bf578f86c47e51e36ff770b9e2a28b5eaee46aed786c`.

`LifecycleBridge`, `AcrtTablesBridge` üzerine CPU `0x18004b26c`, VCRT init `0x18004d55c`, uninit `0x18004d5a8`, thread attach/detach `0x18004d584`/`0x18004d598` ve geç PTD cleanup `0x18004d5c4` gövdelerini bağlar. `PtdEffects`, ayrı 128 baytlık VCRT PTD'sini gerçek kurtarılmış API fallback, calloc/free ve VCRT lock çekirdekleriyle birleştirir. ACRT'nin 968 baytlık kaydı ve slotu ayrıdır. Typed `construct_at` storage üzerinde VCRT nesne ömrünü başlatır; free, trivial nesnenin storage'ını kurtarılmış heap gövdesine iletir.

`LockEffects`, 14 ACRT ve 1 VCRT kilidi için farklı resolver yollarını kullanır. ACRT helper `0x18006707c`, encoded 21 modül/31 yordam cache'ine gider; VCRT helper `0x180050c38`, plain 3 modül/5 yordam cache'ine gider. VCRT BOOL32 sonucu uint32 üzerinden uint64'e taşınır; bit31 sign extension oluşturmaz. `LockPlatform`, initialize ve enter/leave/delete için aynı storage kimliğini sağlamalıdır. ACRT InitializeEffects de aynı bankayı kullanmalıdır. Tercih edilen özgün VA'lar yalnız metadata'dır, pointer olarak çalıştırılmaz.

Provider nesneleri, state ve rebuilt FLS callback bağları geç FLS callback'lerinden uzun yaşamalıdır. LastError getter/setter aynı thread error domain'ini kullanmalıdır. Rebuilt callback açıkça verilmelidir; özgün VA callback'e dönüştürülmez. FLS yoksa kurtarılmış TLS fallback destructor callback'ini düşürür; adapter sahte callback yürütmesi eklemez. Testte explicit thread detach dinamik PTD'yi temizler.

`./build.ps1`, ilgili gerçek kaynak gövdelerini derleyip 443 ortak kontrolü çalıştırır. Process/thread attach–detach, app attach sonucu0x100, iki ayrı PTD, heap sahipliği, 15 kilidin cleanup'ı, iki cache ailesi, FLS ve TLS fallback senaryoları birlikte sınanır. Worker thread değişimi, slotların saklanıp geri yüklenmesiyle simüle edilir; gerçek OS concurrency testi değildir. Heap fixture test programının kendi storage'ını kullanır; native FLS/TLS/loader/critical-section sağlayıcıları çağrılmaz.

`evidence.json` alt modüllerin adresli kanıt kayıtlarına bağlanır. İki bağımsız inceleme kaydı ve birincil takip kaydı, mevcut source snapshot ve ortak doğrulama ayrı tutulur. Ortak derlemede 68 nesne,53 normal grup ve15 terminal senaryo geçti. Native sağlayıcılar, tüm initializer alt sistemleri, stdio/argv/environment, SList, loader, shared globals, SEH/unwind ve bağımsız DLL linkleme tamamlanmadı. Tam runtime eşdeğerliği doğrulanmadı; özgün/yeniden derlenen DLL ve oyun çalıştırılmadı.

Sonraki CRT ortam/cexit aşamasında sentetik test fixture'ları `test_fixtures.hpp` adlı ortak başlığa taşındı; check tanılamasına source_location eklendi. VCRT üretim gövdesi değişmedi. Eski bağımsız inceleme hash'leri önceki test dosyasını temsil eder; güncel test/header hash'leri son ortak build kaydı ve source-snapshot.json içindedir. Aynı fixture'ı yeni startup köprüsü de kullanır.
