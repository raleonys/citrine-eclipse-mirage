## Bağlantının koruması gereken normal akış

- İlk reset: accepted-session kurucusu `023000`, `0230e2` adresinde `02bc70` çağırır. İkinci reset: başarılı accept devamı `025720`, `025777` adresinde ayrı yerel state üzerinde `02bc70` çağırıp sonucu session+0xf0 alanına kopyalar (`025783..025804`). Mevcut typed Session constructor/start bunları iki mantıksal reset olarak modeller. Yeni Handler constructor üçüncü reset eklememelidir. Yerel native reset+kopya ile typed yerinde resetin bellek/exception ABI eşitliği ayrıca açık kalır.
- `02bc70`, `02bc79` ile gerçek cipher constructor `0423d0` çağırır, sonra `02bc81` ile state+0xc4/+0xc5 iki baytını sıfırlar. Yeni bağlantı aynı caller-owned cipher, encrypted ve unknown hücrelerini kullanmalıdır; kendine ayrı flag/cipher kopyaları kurmamalıdır.
- Greeting: `025810 →02d540`, ardından açık string uzunluğunu kullanan bloklu synchronous write-all döngüsü; sonra `025919 →0280d0` okuma. XMLPrinter BufferSize son NUL'ü içerir ve `02d6be →006b30` bunu açık uzunlukla kopyalar. Yeni Handler bu NUL'ü strlen ile kesmemelidir. Mevcut blocking döngü zero-progress için yeni hata icat etmez; transport/scheduling sözleşmeleri ayrıca geçerlidir.
- `02d540`, version globalini her greeting çağrısında `02d5ca..02d5d9` üzerinden okur (`0x1800a3c98`, capacity `0x1800a3cb0`). Yeni bağlantı version hücresini canlı referansla taşımalıdır. Param_1 handler state bu yordamda version snapshot deposu olarak kullanılmaz. Challenge baytları `034cf0`, hex dönüşümü bir kez yapılır; native formatter/allocator davranışı mevcut alt kaynak sınırlarında kalır.
- NUL frame completion `025480`: başarılı read'de unsigned `transferred-1` ve input uzunluğunun min'iyle mesaj kopyalanır; delimiter dahil edilmez. `025556` thread launch, `02557f` detach; başarılı olduktan sonra tampon tüketilir ve `025607 →0280d0` yeniden kurulur. Launch/detach failure önceki tamponu tüketmeden terminal hata yollarına gider. Worker payload raw session pointer taşır; yeni bağlantı bunun ömrünü kendiliğinden güvenli hale getirmez.
- `028d30`: boş mesajda `028d62..028d67` erken çıkar; boş olmayan mesaj `028d99 →033d70` ile işlenir. Sonra `028e7d →021420` yazma callback'ini dispatch eder. **Yanıt string'i boş olsa bile dispatch atlanmaz.** Boş input guard'ı Session düzeyindedir; Handler adapter ayrı bir filtre eklememelidir.
- `033d70` girdi string'ini in-place değiştirir: hex decode/decrypt, parser retry ve version boş öznitelik düzeltmesi. Server Handler API'si string_view olduğundan adapter aynı açık uzunluklu baytların kendi mutable string kopyasını yaratıp çekirdeğe vermelidir; trim, NUL strip, decode veya retry kurallarını yeniden uygulamamalıdır. Encrypted flag değişimi aynı caller hücresine geri görünmelidir.
- Messages Effects içindeki registered_handler çağrısı, mevcut `dispatch::Router::registered_handler` kaynağına aynı rva/request/printer nesneleriyle iletilmelidir. Bridge yeni dispatch tablosu, yeni XML parse, fallback success veya exception çevirisi eklememelidir. Router'ın MemoryPrinter/NodeAccess/type ve reference lifetime ön koşulları ayrıca korunur; diğer logger/error/provider etkileri abstract kalmalıdır.

İncelenen mevcut server/messages normal uygulama akışıyla bu sözleşmeler arasında maddi bir uyumsuzluk bulunmadı. Bu sonuç, tüm ASIO/refcount/allocator/SEH gövdelerinin yeniden incelendiği veya tam native runtime eşitliği olduğu anlamına gelmez. Yeni production kodunun ayrı hashli incelemesi `session-bridge-code-review.md/json` içinde kaydedilecektir.
